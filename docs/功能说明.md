# ClearVoice 程序功能说明

ClearVoice 是一款基于 PySide6 的音视频处理桌面工具。音频算法均在本地离线运行；
语音识别使用魔塔（ModelScope）Paraformer 系列小模型，模型文件放在本地目录后完全离线可用。
翻译与文字转语音支持双后端：本地离线小模型 / OpenAI 兼容大模型 API（本地 Ollama 或线上服务均可），可在设置页切换。

## 一、运行环境与启动

| 项目         | 要求                                                              |
| ------------ | ----------------------------------------------------------------- |
| 操作系统     | Windows（ffmpeg 已在本机 PATH 中）                                |
| Python       | 3.10 ~ 3.12                                                       |
| 包管理       | uv 管理的虚拟环境 `.venv\`                                        |
| 语音识别模型 | `D:\funasrModel`（SeACo-Paraformer 大模型 + FSMN-VAD + 标点模型） |

```powershell
# 激活环境并启动（在项目根目录 d:\projsrc\clearVoice 下）
.venv\Scripts\python.exe -m app.main

# 安装/恢复依赖（含语音识别）
uv sync --extra modelscope

# 运行自检（12 项冒烟测试）
.venv\Scripts\python.exe smoke_test.py
```

### 播放与选区（左栏）

- **播放/暂停、停止**：标准媒体控制；视频与波形播放头同步。
- **倍速播放**：下拉选择 0.25x ~ 4x（0.5x 慢速直接在下拉中选择即可）。
- **波形显示**：立体声文件按 **L / R 双行**显示，单声道单行；底部有**时间刻度尺**
  （步进随缩放自适应：0.01 秒 ~ 1 小时）。
- **波形缩放**：**滚轮**水平滚动视图；**Ctrl+滚轮**以鼠标位置为中心缩放
  （≤10 分钟的文件可放大到采样级细节）；播放中播放头越出视图自动跟随滚动；
  播放头在视图外时波形边缘显示红色三角指示。
- **底部概览条（比例条）**：波形下方显示全长缩略波形与当前视图窗口（黄色框），
  全部支持鼠标拖拽——
  **拖动窗口内部**左右移动视图；**拖动窗口左右边缘**（黄色手柄）以对侧为锚缩放；
  **在窗口外拖拽框选**直接放大到该区间；**双击概览条**复位全览。
  光标随位置变化（抓手 / 左右拉伸 / 十字）。
- **点击波形**：跳转播放位置；**在波形上拖拽**：直接框选区间（拖动超过 6 像素判定为选区）。
- **标记开始 / 标记结束**：以当前播放时刻为边界生成选区，与拖拽选区等价。
- **消音所选段**：把选区音频替换为静音（视频流不重编码）。
- **导出所选段**：精确截取选区为新文件。
- **设为说话人参考 / 设为相似特征参考**：把当前选区作为「指定说话人消除」和「相似特征剔除/分割」的参考音频（波形上分别以绿色/蓝色底色显示）。
- **帧步进（« 帧 / 帧 »）**：按当前视频帧率逐帧前进/后退（显示帧号与 fps），
  配合音画同步微调直观对齐画面与声音。

## 三、功能页签

### 1. 消除杂音

可**多选**的消除类型，按固定顺序依次处理，生成新文件（视频则替换音轨）：

| 选项               | 处理对象                   | 算法                               |
| ------------------ | -------------------------- | ---------------------------------- |
| 杂音 / 噪声        | 宽带稳态噪声               | 谱减法（noisereduce，平稳模式）    |
| 背景音 / 沙沙声    | 持续性背景声、高频嘶声     | 非平稳谱减 + 9kHz 低通 + 平滑      |
| 嘈杂声             | 非平稳嘈杂背景             | 非平稳 + 平稳双重谱减              |
| 哔哔声 / 嘀嘀      | 窄带纯音（报警器、提示音） | STFT 频点显著性检测 + 时频掩蔽     |
| 破音               | 削波失真                   | 削波段样条插值重建                 |
| 背景人声           | 中远场背景说话声           | 300~3400Hz 人声带谱减 + 中频压制   |
| 指定说话人的说话声 | 某个特定人的语音           | log-mel 指纹相似度匹配，命中段静音 |

参数：**降噪强度**（0.1~1.0）、**说话人匹配阈值**（默认 0.70）。
消除「指定说话人」前需先在播放区框选其声音并点击「设为说话人参考」。
「魔塔模型增强」按钮可调用 ZipEnhancer 语音增强模型做整体降噪。

**去背景音乐（人声/伴奏分离）**：基于 torchaudio 内置 HDemucs 离线模型
（MUSDB18-HQ 高质量权重，首次运行自动下载约 320MB 后完全离线）。

- **保留伴奏比例**：0 = 只留人声（默认）；0.3 = 人声 + 30% 伴奏（轻度保留氛围）；不建议取 1（等于接近原始混合，失去去除意义）。
- **同时输出伴奏文件**：勾选后额外生成 `<源>_伴奏.wav`（可另作卡拉 OK 伴奏）。
- 输出与源同目录：视频替换音轨（`<源>_去伴奏.mp4` 等），音频按扩展名编码。
- CPU 上处理速度约为音频时长的 1.5~2 倍，进度条按分块推进。

### 2. 分割

- **定长分割**：按每段固定秒数切分（流拷贝，速度快，切点落在关键帧）。
- **按声音特征分割**：静音边界 / 说话人参考区间 / 相似特征参考，把特征位置作为切点。
- **按关键词 / 正则分割**（需语音识别模型），共 6 种模式：

| 模式                 | 分割点                 | 关键字处理                           |
| -------------------- | ---------------------- | ------------------------------------ |
| 以关键字开头分割     | 关键字首字前「前留白」 | 关键字不入段，下段从关键字结束后开始 |
| 以关键字结束分割     | 关键字末字后「后留白」 | 段连续覆盖全文件，关键字保留在段内   |
| 去掉关键字分割       | 同开头分割             | 另外把关键字及「后留白」一并剔除     |
| 正则前 / 后 / 抹分割 | 同上三种               | 匹配对象为正则表达式                 |

- 前/后留白默认 0.10 秒，可在 0~5 秒间调节。
- 关键词匹配基于去除标点后的识别文本，**跨标点也能命中**；正则示例：`第.{1,3}章`。
- 每处匹配处理后继续向后搜索，循环至文件结束；日志列出全部匹配位置。
- **分割输出选项**：
  - **为每个源文件创建子目录**（默认勾）：输出到 `<源目录>\<源文件名>_<类型>分割\`，
    分段名为 `part_0001` / `piece_0001_起-止` / `seg_001_起-止`。
  - 不勾选：分段文件直接放入源文件目录，文件名加 `<源文件名>_` 前缀区分不同源。
  - **限制文件名长度**：勾选后子目录/前缀中的源文件名主干按设定字符数截断。

### 3. 合并 / 分离

- **音视频合并**：选择视频与音频文件，可设置音频偏移秒数（正=延后）、是否对齐较短流，时间轴自动对齐。
- **分离音频**：从当前打开的文件分离音频，**保留视频原始采样率/声道数**（不重采样、不下混），
  输出格式可选：WAV（无损 PCM）、FLAC（无损压缩）、MP3（高品质 VBR）、M4A/AAC 192k、
  OGG Vorbis、OPUS 128k（OPUS 编解码标准固定 48kHz）。输出 `<源>_音频.<格式>`。

### 4. 格式转换

批量媒体转换（**视频转音频 / 音频转音频**），支持**文件与目录混合选择**：

- **添加文件 / 添加目录**：添加目录时递归穷举子目录中的音视频文件（可关「递归子目录」）；
  列表可移除所选/清空。
- **输出根目录**：留空 = 输出到源文件同目录；指定后配合「输出保持相对目录结构」
  在根目录下**按源相对路径重建子目录**。
- **输出格式**：WAV（无损）/ FLAC（无损）/ MP3 / M4A·AAC / OGG / OPUS（OPUS 固定 48kHz）。
- **码率**：默认跟随编码器默认（MP3 为 VBR 高品质），可选 128k/192k/256k/320k 或手填；
  无损格式（WAV/FLAC）忽略码率。
- **采样率**：默认**跟随源文件**，可选 8k/16k/22.05k/32k/44.1k/48k。
- **降噪率**：勾选后按 0.1~1.0 强度做稳态谱减降噪（经 wav 中间流程 DSP 处理，保留源声道数）。
- **限制文件名长度**：勾选后输出文件名主干超过设定字符数自动截断（保留扩展名）；
  同名文件自动加 `_1/_2` 序号。

### 5. 文件名/夹处理（批量重命名）

对指定目录（可递归子目录）按扩展名过滤批量重命名，**先预览后执行**（对齐 xrename.bat）：

| 模式          | 说明                                             | 参数            |
| ------------- | ------------------------------------------------ | --------------- |
| 字符串替换    | 文件名中的查找串替换为替换串（替换串留空=删除）  | 查找串 / 替换串 |
| 保留子串 keep | 从第 n 位起保留 m 位；m 为负=保留到倒数 \|m\| 位 | n / m           |
| 左切除 lcut   | 去掉前 m 位                                      | m               |
| 中间切除 cut  | 删除第 n 到 m 位之间的字符（保留前后）           | n / m           |

- 位置为 **0 基字符索引**（中文按字计），支持负数。
- 安全保护：结果为空、名称未变化自动跳过；目标已存在可「自动加序号」或跳过；
  执行前弹确认框；预览区显示完整 旧→新 对照。
- 可选结果名超长截断（主干字符数）。

### 6. 时间轴

- **变速**：0.1x~8x 音视频同步变速（视频 setpts + 音频 atempo 链，自动串联突破 0.5~2.0 限制）。
- **音画同步微调**：视频音频不同步时，把音频相对画面**提前或推迟**（±10 秒，步进 0.05 秒）。
  正值 = 音频延后（推迟播放），负值 = 音频提前。流程：
  1. **试听预览**：从播放当前位置生成 20 秒校准片段（视频音频均重编码保证对齐准确）并自动播放；
  2. 微调偏移量反复试听，满意后点**恢复播放原文件**回到原视频；
  3. **应用到文件**：生成 `<源>_同步±X.Xs.ext` 新文件（视频流 copy 不损画质，音频重编码 aac；
     正偏移尾部对齐视频长度，负偏移视频保持全长、结尾静音）。
- **裁剪**：把文件裁剪为当前所选区间。

### 7. 特征剔除

- **按语言文字特征剔除**：输入逗号分隔关键词，语音识别后命中句所在时间段可「静音」或「剪切」。
- **按相似音频特征剔除**：以标记区间或导入的参考音频为特征，相似段可「静音」或「剪切」，阈值默认 0.78。

### 8. 语音转文字

选择任意音频/视频文件（默认带入当前打开的文件），可同时勾选输出：

- **文本文档 `*.txt`**：每句一行纯文本。
- **字幕文件 `*.srt`**：标准 SRT，`时:分:秒,毫秒` 时间轴，可直接导入播放器/剪辑软件。
- **歌词文件 `*.lrc`**：`[分:秒.厘秒]` 行级时间戳。

输出与源文件同目录同名；完成后日志显示全部生成文件与文本预览。
首次识别自动加载本地模型（`D:\funasrModel`），无需联网。

### 9. 翻译 / TTS

#### 音频翻译（语音识别 → 翻译 → 双语导出）

选择音频/视频文件，选择翻译方向后一键执行：语音识别（带时间戳）→ 逐句翻译 → 生成三种双语文件：

| 翻译方向 | 说明        |
| -------- | ----------- |
| 英译中   | 英语 → 中文 |
| 中译英   | 中文 → 英语 |
| 日译中   | 日语 → 中文 |

输出（与源文件同目录）：

- **`<源>.翻译.txt`**：双语对照文本，每句两行（原文 / 译文）。
- **`<源>.双语.srt`**：双语字幕，每条字幕两行（原文在上、译文在下）。
- **`<源>.双语.lrc`**：双语歌词，同一时间戳一行，原文与译文用「 / 」分隔。

翻译后端（设置页可选）：

- **本地小模型**：M2M100 多语言翻译模型（约 418M 参数，完全离线）。
  首次使用自动从 HF 镜像（hf-mirror.com）下载；也可在设置页指定已下载的权重目录。
- **OpenAI 兼容大模型 API**：走 `/v1/chat/completions` 接口。
  `API Base URL` 指向本地大模型（如 Ollama `http://localhost:11434/v1`）或线上服务均可；
  逐句翻译，系统提示词约束只输出译文。

#### 文字转语音（中 / 英 / 粤）

输入文本，选择音色，输出 MP3（留空路径自动命名到 `tts_out\`）：

| 音色            | 语言   |
| --------------- | ------ |
| 中文（女·晓晓） | 普通话 |
| 中文（男·云希） | 普通话 |
| 英语（女·Aria） | 英语   |
| 英语（男·Guy）  | 英语   |
| 粤语（女·曉曼） | 粤语   |
| 粤语（男·雲龍） | 粤语   |

TTS 后端（设置页可选）：

- **edge-tts**（默认）：微软线上免费合成，需要联网，无需 API Key。
- **OpenAI 兼容 TTS API**：走 `/v1/audio/speech` 接口（本地 TTS 服务或线上 API）。

### 10. 设置

- **funasr 模型根目录**：默认 `D:\funasrModel`，自动在其下查找 `hub\iic\<模型名>`；找到 `config.yaml` 即视为有效模型目录。
- **运行设备**：cpu / cuda（当前 torch 为 CPU 版，选 cuda 前需自行安装 GPU 版）。
- **分离模型目录**（可选）：HDemucs 权重目录，放入 `hdemucs_high*.pt` 即可；留空使用内置缓存
  （`~/.cache/torch/hub/torchaudio/models/hdemucs_high_trained.pt`）。
- **翻译后端**：本地 M2M100 小模型 / OpenAI 兼容大模型 API。
- **翻译模型目录**（可选）：M2M100 权重目录，含 `config.json` 即用本地权重；留空自动下载（HF 镜像）。
- **TTS 后端**：edge-tts（线上免费）/ OpenAI 兼容 TTS API。
- **API Base URL / API Key / 对话模型名**：OpenAI 兼容服务参数
  （本地大模型如 Ollama：`http://localhost:11434/v1` + `qwen2.5:7b`；线上服务填对应地址、密钥与模型名）。
- 保存至 `C:\Users\<用户>\.clearvoice_config.json`，保存后下次识别/翻译/合成生效（识别模型自动重载管线）。

## 四、输出文件约定

所有「生成新文件」的操作都不覆盖源文件，输出与源文件同目录：

| 操作          | 输出                                                            |
| ------------- | --------------------------------------------------------------- |
| 消除杂音      | `<源>_消除_<类型列表>.mp4/.m4a`（附同名 `.wav` 中间产物）       |
| 消音所选段    | `<源>_静音段.mp4/.m4a`                                          |
| 导出所选段    | `<源>_片段起-止.扩展名`                                         |
| 定长/特征分割 | `<源>_定长分割\part_0001…`（不建子目录时为 `<源>_part_0001…`）  |
| 关键词分割    | `<源>_关键词分割\seg_001_起-止…`（不建子目录时加 `<源>_` 前缀） |
| 文字/相似剔除 | `<源>_文字剔除.*` / `<源>_相似剔除.*`                           |
| 去背景音乐    | `<源>_去伴奏.mp4/.m4a/…`（可选 `<源>_伴奏.wav`）                |
| 音视频合并    | `<视频名>_合并.mp4`                                             |
| 分离音频      | `<源>_音频.wav/.flac/.mp3/.m4a/.ogg/.opus`（原采样率/声道）     |
| 格式转换      | `<输出根目录>\<源相对路径>\<源名>.<格式>`（重名加 `_1/_2`）     |
| 批量重命名    | 源目录内直接改名（预览确认后执行，空名/重名保护）               |
| 语音转文字    | `<源>.txt` / `<源>.srt` / `<源>.lrc`                            |
| 音频翻译      | `<源>.翻译.txt` / `<源>.双语.srt` / `<源>.双语.lrc`             |
| 文字转语音    | `<输出>.mp3`（留空自动命名到 `tts_out\`）                       |
| 变速 / 裁剪   | `<源>_x2.*` / `<源>_裁剪起-止.*`                                |

任务完成后程序会询问是否把输出加载到播放器预览。
