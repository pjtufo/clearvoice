# ClearVoice 设计说明

## 一、总体架构

```
app/main.py                 启动入口（HighDPI 策略、QApplication）
  └─ app/main_window.py     MainWindow（PySide6）+ Worker 线程 + WaveformWidget
       ├─ app/audio_ops.py      杂音消除 DSP 管线（numpy/scipy/noisereduce）
       ├─ app/features.py       特征检测：相似度指纹 / 哔哔 / 破音 / 静音
       ├─ app/ffmpeg_tools.py   ffmpeg/ffprobe 命令行封装（所有媒体 IO）
       ├─ app/asr.py            魔塔 funasr 语音识别 + 导出 + 关键词定位
       ├─ app/separation.py     人声/伴奏分离（torchaudio HDemucs）
       ├─ app/translator.py     文本翻译（M2M100 本地 / OpenAI 兼容 API）+ 双语导出
       ├─ app/tts.py            文字转语音（edge-tts / OpenAI 兼容 API）
       └─ app/config.py         用户配置持久化（JSON）
smoke_test.py               冒烟测试（12 项，offscreen 可跑）
pyproject.toml              uv 项目定义（base + modelscope extra）
```

分层原则：

- **界面层**（main_window）只做参数收集、任务下发与结果呈现，不写算法；
- **算法层**（audio_ops/features）只操作 `numpy` 数组，不关心文件格式；
- **媒体 IO 层**（ffmpeg_tools）统一经 ffmpeg 解码/编码，天然支持任意音视频格式；
- **模型层**（asr）惰性加载，加载失败只影响相关功能，不阻塞其余功能。

## 二、线程与任务模型

`Worker(QThread)`：统一后台任务封装，信号 `progress(int,str)` / `done(str,object)` / `failed(str,str)`。
主窗口 `_run()` 保证同一时刻只有一个任务（`_busy` 互斥），任务函数以 `progress_cb` 关键字接收进度回调。
结果约定：返回 `str`（提示）、`list[str]`（文件列表）或 `dict{"output","report","matched"}`，
`_default_done` 统一解析并弹窗询问是否加载预览。

媒体播放使用 `QMediaPlayer + QAudioOutput + QVideoWidget`，`positionChanged` 驱动波形播放头。

## 三、波形控件 WaveformWidget

- 打开文件后经 `audio_ops.load_wav(16k)` 取单声道波形，按像素列聚合为 min/max 包络绘制。
- 交互：`mousePressEvent→Move→Release`；位移 >6px 判定为拖拽选区（`selection_drawn` 信号），
  否则视为点击定位（`clicked` 信号）。
- 三种选区着色：说话人参考（绿）、相似特征参考（蓝）、当前选区（橙），标记状态与右侧功能联动。

## 四、关键算法

### 4.1 相似音频特征 / 说话人指纹（features.py）

- 特征：0.5s 窗 / 0.25s 步的 40 维 log-mel 谱（`logmel_sequence`）。
- 归一化：对目标音频做**倒谱均值归一化（CMN）**——减去各频点时间均值，
  参考片段也投影到同一空间（`ref_emb = mean(sel - mu)`），消除录音通道差异。
- 参考端选择能量前 60% 的窗口参与均值，静音帧（能量低于峰值 6dB）相似度置 -1 不参与判定。
- 参考过短（<1.5s）时自适应缩短参考窗长（下限 0.12s、≥4 窗），避免均值退化。
- `find_similar_segments`：阈值化相似度曲线 + 连续帧合并（最短 0.3s）。
- 阈值经验值：说话人消除 0.70、相似特征剔除 0.78、特征分割 0.80。

### 4.2 哔哔声检测与消除

STFT（4096 点 / 75% 重叠）后逐频点判定：
`显著度 = 频点能量中位数 / 邻域(21 bins)滑动均值`，取 97 分位以上候选；
频点能量超过全带中位数 4 倍且持续 ≥0.4s 判为哔哔。消除采用时频掩蔽（命中时段掩蔽至 0.05）。

### 4.3 破音修复

`|x| ≥ 0.985` 的连续段视为削波；长度 ≤ 1/20 总长的段用边界良好样本做 **CubicSpline 插值重建**
（失败退化为线性插值），超过阈值长度的段不动，最后限幅。

### 4.4 消除管线（audio_ops.process_removals）

按 REMOVAL_TYPES 固定顺序执行所选类型（多选叠加），每步后限幅 [-1,1]；
`speaker` 类型需外部传入参考音频，命中段静音并加 20ms 淡出防爆音。

### 4.5 ffmpeg 封装要点（ffmpeg_tools.py）

| 函数                             | 方案                                                                              |
| -------------------------------- | --------------------------------------------------------------------------------- |
| `extract_audio`                  | `-vn -ar -ac pcm_s16le`，支持 `-ss/-t` 区间，是所有 DSP 的解码入口                |
| `mute_ranges`                    | `volume=enable='between(t,..)+..':volume=0` 一条滤镜多段静音，视频流 copy         |
| `remove_ranges`                  | 保留段逐一重编码 → concat demuxer 拼接（时间轴连续、帧精确）                      |
| `cut_range`                      | `-ss -to` + 按扩展名重编码（x264 veryfast crf20 / mp3 q2 / aac 192k），保证帧精度 |
| `split_fixed`                    | segment muxer 流拷贝，切点落在关键帧                                              |
| `change_speed`                   | 视频 `setpts=PTS/speed` + 音频 `atempo` 链（0.5~2.0 外自动串联），v/a 同步        |
| `merge_av` / `mux_replace_audio` | `-itsoffset` 控制音频偏移，`-shortest` 对齐，视频流 copy 零转码                   |

## 五、语音识别子系统（asr.py）

### 5.1 模型与本地化

- 模型：`iic/speech_seaco_paraformer_large_asr_nat-zh-cn-16k-common-vocab8404-pytorch`
  （ASR，字级时间戳）+ `iic/speech_fsmn_vad_zh-cn-16k-common-pytorch`（切分）
  - `iic/punc_ct-transformer_zh-cn-common-vocab272727-pytorch`（标点，可选）。
- `_local(model_id)`：按设置页「模型根目录」依次探测 `<根>/<模型名>`、`<根>/hub/iic/<模型名>`、
  `<根>/iic/<模型名>`，存在 `config.yaml` 即用本地路径（**完全离线**）；否则回退模型 ID 自动下载。
- `punc_model` 加载失败时自动降级为无标点管线重试一次。
- `reset_pipeline()`：设置变更后清空缓存管线，下次调用按新配置重载。
- 惰性加载：未安装 funasr 时 `asr_available()=False`，界面给出安装提示而不是崩溃。

### 5.2 字级定位（关键词/正则分割的基础）

```
generate() → sentence_info[{text,start,end(ms)}…]
  → transcribe_words(): 滤除纯标点 token → 字级序列 words
  → find_occurrences():
      parts[i] = words[i].text 去标点
      text     = concat(parts)          # 无标点连接文本
      idx[c]   = 字符位置 → 词索引映射    # len(idx) == len(text)
      keyword  → str.find 循环非重叠命中
      pattern  → re.finditer
      命中 (a,b) → 时间 (words[idx[a]].start, words[idx[b-1]].end)
```

匹配在去标点文本上进行，因此「大家好，今天」中查 `好今天` 也能命中；
时间取首字符词起点与末字符词终点，粒度即 funasr 字级时间戳（约 10~20ms）。

### 5.3 分割段计算（compute_split_segments）

三种策略（head/tail/erase），维护游标 `cur`：

- `head`：段止于 `hit.start - pad_before`，`cur = hit.end`（关键字不入段）；
- `tail`：段止于 `hit.end + pad_after`，`cur = 该分割点`（段连续覆盖全文件）；
- `erase`：段止于 `hit.start - pad_before`，`cur = hit.end + pad_after`（关键字与后留白均剔除）；
- 过滤 <50ms 碎段；`occ` 为空时按模式返回剩余整段或不分割。

### 5.4 导出格式

SRT：`HH:MM:SS,mmm --> HH:MM:SS,mmm`（句级起止）；
LRC：`[mm:ss.xx]文本`（句起点），头部可写 `[ti:文件名]`；
TXT：每句一行。全部 UTF-8。

## 六、人声/伴奏分离子系统（separation.py）

- **模型**：torchaudio 内置 `HDEMUCS_HIGH_MUSDB_PLUS`（HDemucs，MUSDB18-HQ 高质量权重，
  4 音轨 drums/bass/other/vocals，输入输出 44.1kHz 立体声）。
  权重首次运行自动下载到 `~/.cache/torch/hub/torchaudio/models/`（约 320MB），此后离线。
  选型说明：魔搭 `DiffSynth-Studio/Demucs-Repackage` 是同一 Demucs 架构的魔搭转存，
  但需引入 DiffSynth-Studio 全套依赖；torchaudio 内置方案零新增依赖，故采用后者。
- **权重解析顺序**：设置页「分离模型目录」（`demucs_model_dir`）→ torch 内置缓存 → 自动下载。
- **分块推理**（`_chunked_separate`）：10s 窗 / 75% 跳步，窗间线性渐变交叠，
  首窗免渐入、末窗免渐出，按累计权重归一化（partition-of-unity），长音频内存恒定。
- **输出合成**：人声 = vocals 轨；伴奏 = drums+bass+other；最终输出 = 人声 + keep_ratio×伴奏，
  峰值归一后以 PCM_16 写 WAV。
- **IO**：读写用 soundfile（torchaudio 2.9+ 的 load/save 依赖 torchcodec，未采用）；
  重采样用 `torchaudio.functional.resample`（纯张量运算，无后端依赖）。
- **回写媒体**：视频源经 `mux_replace_audio` 换音轨（视频流 copy）；音频源按扩展名编码。

## 七、翻译与语音合成子系统（translator.py / tts.py）

### 7.1 音频翻译流水线（main_window.\_job_translate）

```
媒体文件 → ffmpeg extract_audio(16k mono)
        → asr.transcribe_with_timestamps()   # 句级 {text,start,end}
        → translator.translate(逐句)          # 按配置后端
        → sents[i]["trans"] = 译文
        → 双语导出: .翻译.txt / .双语.srt / .双语.lrc
```

### 7.2 翻译双后端（translator.py）

- **本地 M2M100**（`translate_texts_local`）：`facebook/m2m100_418M`，
  `AutoTokenizer + AutoModelForSeq2SeqLM`，按 batch=8 批量编码，
  `forced_bos_token_id` 指定目标语言；权重解析顺序：
  设置页「翻译模型目录」（存在 `config.json`）→ HF 镜像（`HF_ENDPOINT=https://hf-mirror.com`）自动下载。
- **OpenAI 兼容 API**（`translate_texts_llm`）：`POST {api_base}/chat/completions` 逐句调用，
  系统提示词约束「只输出译文本身」；`api_base` 指向本地（Ollama）或线上均可，
  `api_key` 非空时携带 Bearer 头。
- `translate()` 按 `translate_backend`（local/api）分发。

### 7.3 双语导出（translator.py）

- TXT：每句两行（原文/译文）+ 空行；
- SRT：复用 `asr._fmt_srt`，每条字幕两行（原文在上、译文在下）；
- LRC：复用 `asr._fmt_lrc`，同一时间戳一行，原文与译文用「 / 」拼接。

### 7.4 文字转语音（tts.py）

- 音色表 `VOICES`：6 个 edge-tts 音色（中文普通话 x2、英语 x2、粤语 x2），
  音色 ID 同时用作 OpenAI 兼容 API 的 `voice` 参数。
- **edge-tts 后端**（`_synth_edge`）：`edge_tts.Communicate(text, voice).save(out)`，
  asyncio 运行，输出 MP3，需联网、免费无 Key。
- **OpenAI 兼容后端**（`_synth_api`）：`POST {api_base}/audio/speech`，
  payload `{model: tts_api_model, voice, input, response_format: "mp3"}`，响应体直接写文件。
- `synth()` 按 `tts_backend`（edge/api）分发。

## 八、配置持久化（config.py）

`~/.clearvoice_config.json`，白名单键：
`funasr_model_dir`、`asr_device`、`demucs_model_dir`、
`translate_backend`、`translate_model_dir`、
`tts_backend`、`tts_api_model`、
`api_base`、`api_key`、`api_model`。
读入时过滤未知键并合并默认值，写入失败静默（不影响功能）。

## 九、错误处理与可诊断性

- ffmpeg 调用统一 `run()`：非零退出抛 `FFmpegError`（附 stderr 末 3000 字符）；
- 后台任务异常在 `Worker.run` 捕获，经 `failed` 信号带回堆栈写日志并弹窗；
- Windows 下 `CREATE_NO_WINDOW` 防止 ffmpeg 弹黑框。

## 十、已知限制

1. 相似特征/说话人匹配基于传统 DSP 指纹，对高度相似的双人语音区分度有限；
   如需更强效果可替换为说话人嵌入模型（如魔塔 CAM++），接口 `find_similar_segments` 不变。
2. 「指定说话人消除」「文字特征剔除」等对长文件先全量解码到 16k 内存波形，超长（>2h）文件内存占用较高。
3. 定长分割为关键帧对齐（流拷贝），切点误差最多一个 GOP；需要精确切点时改用「导出所选段」（重编码）。
4. 当前 torch 为 CPU 版，「设置→cuda」需自行安装匹配的 GPU 版 torch。
5. 人声/伴奏分离在 CPU 上速度约为音频时长的 1.5~2 倍；对纯语音（无音乐）内容会把语音判入
   「other/伴奏」轨，建议仅对含背景音乐的内容使用。
6. Windows PowerShell 执行策略为 Restricted 时，仅影响部分工具宿主 profile 脚本加载（无害告警），程序本身不受影响。
7. 翻译本地 M2M100 为小参数量级模型，专业术语与长句质量不及大模型；追求质量可在设置页切换
   OpenAI 兼容大模型 API（本地 Ollama 或线上服务）。首次使用本地模型需联网下载约 1.8GB 权重（或提前放置权重目录）。
8. edge-tts 依赖微软线上服务，需联网；离线场景请改用 OpenAI 兼容 TTS API（本地部署的 TTS 服务）。
9. API 翻译逐句请求，长音频句数多时耗时随句数线性增长；Ollama 默认并发为 1。
